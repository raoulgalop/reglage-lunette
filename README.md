# Réglage Lunette

Application de balistique et de réglage de lunette : tables PR/TLD, abaques de vent, réticule, journal de tir et cibles.

Version web installable sur iPhone : ouvrir https://raoulgalop.github.io/reglage-lunette/ dans Safari, puis Partager → « Sur l'écran d'accueil ».

Le même code est aussi compilé en application Android (WebView).
